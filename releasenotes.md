# 🥗 Fitomi Release Notes



**v1.4.2**

2026-10-19

- Cookbook and recipe images are now stored in the cloud
- Images sync across multiple devices and in shared cookbooks and lists
- Improvements to usability and design
- Updated libraries and fixed security vulnerabilities

---

**v1.4.1**

2026-10-05

- New: Meal Planner - plan your entire week ahead
- Diary: portions can now be logged in steps of 0.25
- Diary: recently added items are now shown for quick access
- Shopping list now uses fixed units
- Adding a manual ingredient to a recipe now takes you straight to the nutrition entry screen. This can be turned off in the settings
- UI fixes and improvements

---

**v1.4.0**

2026-09-28

- Shopping list revamped: items are now automatically sorted by category in a sensible order (e.g., fruits and vegetables first)
- Added new categories to the diary
- Diary categories can now be shown or hidden as you like
- Diary entries can now be easily copied to other days
- A confirmation prompt now appears before deleting a diary entry, to prevent accidental deletions
- Recipe images are now displayed correctly in all search results
- Bug fixes and improvements
